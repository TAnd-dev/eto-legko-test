# speedtest.py

Консольный скрипт: делает 10 последовательных запросов к указанному адресу, дожидается полного ответа на каждый и печатает среднее время запроса, общий объём скачанного и скорость скачивания.

## Требования

Python 3.8 или новее. Зависимостей нет, используется только стандартная библиотека.

## Запуск

```bash
python3 speedtest.py <адрес>
```

Например:

```bash
python3 speedtest.py https://proof.ovh.net/files/10Mb.dat
```

Адрес с `?` или `&` берите в кавычки, иначе их разберёт оболочка.

```
 6/10      2766 мс     10.49 МБ

Всего скачано:         104.86 МБ
Скорость скачивания:   41.95 Мбит/с (5.24 МБ/с)
```

## Единицы измерения

| Величина | Единица | Как считается |
| --- | --- | --- |
| Время одного запроса | миллисекунды (мс) | от отправки запроса до последнего байта ответа |
| Среднее время запроса | секунды (с) | сумма времён / 10 |
| Объём | мегабайты (МБ) | 1 МБ = 1 000 000 байт |
| Скорость скачивания | мегабиты в секунду (Мбит/с) | весь объём × 8 / 1 000 000 / суммарное время |

Скорость дополнительно выводится в МБ/с в скобках. Приставки десятичные (10⁶), не двоичные: так скорость указывают провайдеры, и число можно сравнивать с тарифом.

## Что учитывается

- Запросы идут строго по очереди, следующий начинается после полного чтения предыдущего ответа.
- Время запроса включает установку соединения, TLS, ожидание заголовков и скачивание тела. Каждый запрос открывает новое соединение.
- Считаются байты тела ответа в том виде, в каком они пришли по сети. Сжатие скрипт не запрашивает.
- Ответ читается кусками по 64 КБ и на диск не сохраняется, поэтому размер файла память не ограничивает.
- Таймаут на сетевые операции: 30 секунд.

## Ошибки

Если любой из 10 запросов не удался (сеть, таймаут, ответ 4xx/5xx), скрипт печатает причину в stderr и завершается с кодом 1, итоговая статистика не выводится. Некоторые сайты ограничивают частоту запросов и на тяжёлый файл могут ответить `429 Too Many Requests` (так делает, например, Wikimedia).

При неверном или пропущенном адресе код выхода 2.

Сертификаты HTTPS проверяются. У Python, установленного с python.org на macOS, корневых сертификатов может не быть: тогда скрипт берёт их из пакета `certifi`, если он установлен. Если нет, запустите `Install Certificates.command` из папки Python в «Программах» или выполните `pip install certifi`.
